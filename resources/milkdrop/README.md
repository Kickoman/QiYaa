# Built-in Milkdrop presets

150 presets picked from the projectM team's
["Cream of the Crop" collection](https://github.com/projectM-visualizer/presets-cream-of-the-crop)
(curated by ISOSCELES), commit `0180df21f5e0bd39b9060cc5de420ed2f1f9e509`: a few from each category, only ones that
need no extra textures, load in projectM 4.1 and render something lively on
a software renderer. File names are the original ones prefixed with the
category, with characters other than ASCII letters, digits and `_-()+,.!'#`
replaced by `_`; the contents are unchanged except for line endings.

Milkdrop presets were mostly released without a specific license. The
collection's own notice: "Theoretically, each preset author holds the full
copyright on any released presets. Since the presets were freely released and
have been used in so many packages and applications in the past two decades,
it is safe to assume them to be in the public domain. If any preset author
doesn't want their own creation in this repository, please contact the
projectM team and we will remove the preset(s) from future releases." QiYaa
will remove any preset on request as well. The authors are named in the file
names.

Your own presets go to `~/.config/QiYaa/milkdrop` (Windows:
`%LOCALAPPDATA%\QiYaa\milkdrop`; Milkdrop menu → "Открыть папку своих пресетов").

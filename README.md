# QiYaa

Плеер Яндекс Музыки в стиле Winamp 2 на C++/Qt 6 — переписанный [Yaamp](https://github.com/Kickoman/yaamp) без Electron: настоящие окна ОС, классические скины `.wsz`, минимум CPU.

> **Статус: этап 1 (MVP).** Главное окно, эквалайзер и плейлист со стыковкой, меню Яндекс Музыки, вход, визуализация. Дальше — этап 2 (паритет с Yaamp): свёрнутые режимы окон, «Сейчас играет», медиаклавиши, фидбек волне.

## Что умеет

**Окна.** Главное окно, эквалайзер и плейлист — настоящие окна ОС. Главное окно тащит за собой пристыкованные; любое окно прилипает к другим и к краям экрана (15 px) и **не может уйти за пределы экрана**, в том числе после отключения монитора. Позиции, видимость и размер плейлиста запоминаются. Свёрнутое главное окно уводит с собой остальные.

**Скины.** Winamp 2.x (`.wsz`), 8 встроенных + свой файл. Форма окон по `region.txt`, цвета плейлиста из `pledit.txt`, визуализации из `viscolor.txt`. Кириллица в бегущей строке рисуется «родным» пиксельным шрифтом скина.

**Размер.** 100–300 % (меню → Размер; Ctrl+D — двойной). Дробные размеры рисуются через целое увеличение с плавным уменьшением.

**Эквалайзер.** 10 полос (60 Гц … 16 кГц) ± 12 дБ + преусилитель, ON, 17 встроенных пресетов Winamp, график кривой. Двойной клик по ползунку — 0 дБ, колесо мыши — шаг 0,5 дБ. Настройки сохраняются.

**Плейлист.** Текущая очередь: выбор (Ctrl/Shift), двойной клик/Enter — играть, Delete — удалить, прокрутка колесом и ползунком, изменение размера за правый нижний угол (шаги 25×29 px), кнопки REM/SEL и мини-транспорт, общее время.

**Главное окно.** Транспорт, перемотка, громкость, баланс, shuffle/repeat, kbps/kHz, моно/стерео. Клик по времени — оставшееся время, клик по визуализации — спектр → осциллограф → выкл. Бегущая строка показывает и подсказки (громкость, баланс, EQ, перемотка).

**Яндекс Музыка** (правый клик по любому окну, кнопка Eject или ADD в плейлисте):
Моя волна (бесконечная — треки догружаются), Мне нравится, Плейлисты, Исполнители (популярные треки), Альбомы, Станции (по разделам), Поиск (лучший результат: исполнитель/альбом/треки); для текущего трека — Нравится/убрать, Не нравится (с переходом к следующему), открыть в браузере. Отметки прослушивания отправляются.

**Горячие клавиши** (как в Winamp): Z/X/C/V/B — назад/играть/пауза/стоп/вперёд, ←/→ — перемотка на 5 с, Alt+G — эквалайзер, Alt+E — плейлист, Ctrl+D — двойной размер.

**Ресурсы.** Когда ничего не играет — ни таймеров, ни аудиоколбэков (CPU ≈ 0). Визуализация перерисовывает только свой прямоугольник ~30 раз в секунду и только когда окно видно.

## Вход в Яндекс Музыку

При первом запуске (или через меню → «Войти…») открывается окно входа:

1. **Код устройства** — откройте ya.ru/device в любом браузере (хоть на телефоне) и введите показанный код; QiYaa дождётся подтверждения сама.
2. **Если код не сработал** — «Открыть страницу входа», войдите в браузере, скопируйте адрес страницы, на которую вас перенаправит (`music.yandex.ru/#access_token=…`), и вставьте в поле.

Токен хранится в `~/.config/QiYaa/token` (Windows: `%LOCALAPPDATA%\QiYaa\token`) с правами только для владельца. Если Yaamp уже был залогинен, токен из его `token.json` подхватывается автоматически. Переменная окружения `QIYAA_TOKEN` имеет приоритет. «Выйти из аккаунта» в меню удаляет токен.

## Сборка

Нужны CMake ≥ 3.21, компилятор C++20 и Qt ≥ 6.4 (Core, Gui, Widgets, Network). Остальное (miniaudio, miniz) лежит в `third_party/`.

### Ubuntu 24.04

```sh
sudo apt install build-essential cmake ninja-build qt6-base-dev libgl1-mesa-dev
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=RelWithDebInfo
cmake --build build
ctest --test-dir build --output-on-failure
./build/QiYaa
```

Для звука miniaudio сам подгружает PulseAudio/PipeWire/ALSA во время работы — dev-пакеты не нужны.

### Windows

Qt 6.8 через [онлайн-установщик](https://www.qt.io/download-qt-installer-oss) (компонент MSVC 2022 64-bit), затем в «x64 Native Tools Command Prompt»:

```bat
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH=C:\Qt\6.8.3\msvc2022_64
cmake --build build
C:\Qt\6.8.3\msvc2022_64\bin\windeployqt build\QiYaa.exe
```

Готовые сборки под Linux, Windows и macOS появляются в артефактах GitHub Actions.

## Параметры командной строки

| Параметр | Что делает |
|---|---|
| `--play-file <путь>` | Играть локальный mp3/flac/wav вместо Яндекса (проверка звука) |
| `--offline` | Не подключаться к Яндексу |
| `--skin <file.wsz>` | Скин на этот запуск |
| `--screenshot <png>` | Отрисовать все окна в PNG и выйти (работает с `QT_QPA_PLATFORM=offscreen`); вместе с `--play-file` — через секунду воспроизведения |
| `--demo` | Заполнить плейлист примерами (проверка интерфейса без аккаунта) |
| `--scale <x>` | Размер окон на этот запуск, например `1.5` |
| `--text <текст>` | Показать текст в бегущей строке (для скриншотов) |

## Wayland

Wayland не даёт приложениям ставить свои окна в нужные координаты, а на этом держится Winamp (окна прилипают друг к другу). Поэтому на Linux по умолчанию QiYaa запускается через XWayland (`QT_QPA_PLATFORM=xcb;wayland`). Нативный режим: `QIYAA_NATIVE_WAYLAND=1` — окно двигает композитор, без прилипания и запоминания позиции. Если вы сами задали `QT_QPA_PLATFORM`, выбор не меняется.

## Структура

```
src/app      App (сборка всего вместе: окна, меню, настройки, вход), main(), пути
src/skin     загрузка .wsz, спрайты, region.txt, pledit.txt
src/ui       SkinnedWindow (окно без рамки, маска, стыковка), Snap,
             MainWindow, EqualizerWindow, PlaylistWindow, LibraryMenu, LoginDialog
src/vis      интерфейс Visualizer, FFT, спектр и осциллограф
src/yandex   ApiClient, Library (источники), OAuth (код устройства), подпись ссылки, токен
src/audio    AudioEngine: загрузка → поток декодера → кольцевой буфер → EQ → VisTap → громкость → miniaudio
src/core     Player: очередь, бесконечные источники, next/prev/shuffle/repeat
tests/       Qt Test: DSP, окна, API Яндекса против локального mock-сервера, звук
```

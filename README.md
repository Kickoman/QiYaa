# QiYaa

Плеер Яндекс Музыки, Spotify и своих файлов в стиле Winamp 2 на C++20 и Qt 6 — переписанный
[Yaamp](https://github.com/Kickoman/yaamp) без Electron: настоящие окна ОС, которые прилипают друг
к другу, классические скины `.wsz`, эквалайзер, визуализации Winamp и Milkdrop, тексты песен,
треки без пауз, медиаклавиши и джем — общая очередь для компании. Работает на Linux, Windows и
macOS; для телефона есть [QiYaa для Android](https://github.com/Kickoman/QiYaa-android). Сайт —
[qiyaa.kanstancin.net](https://qiyaa.kanstancin.net).

## Окна и режимы

| Окно | Что там | Как открыть |
|---|---|---|
| Главное | Транспорт, время, бегущая строка, спектр или осциллограф, громкость, баланс, shuffle/repeat | Всегда открыто |
| Эквалайзер | 10 полос, преусилитель, 17 пресетов Winamp, `.eqf` | Alt+G, кнопка EQ |
| Плейлист | Текущая очередь, выбор, удаление, общее время | Alt+E, кнопка PL |
| «Сейчас играет» | Обложка, исполнители, альбом, год, «Мне нравится» | Меню → «Сейчас играет» |
| Текст песни | Текст текущего трека из Яндекс Музыки, `.lrc` и тегов своих файлов, по желанию из LRCLIB; синхронная строка идёт за музыкой, клик перематывает | Alt+L, меню → «Текст песни» |
| Milkdrop | Визуализация projectM, 150 пресетов, полный экран | Ctrl+Shift+K, меню → Milkdrop |
| Свёрнутый режим | Любое из первых трёх окон — полоска высотой 14 px | Двойной клик по заголовку, Ctrl+W |
| Меню Яндекс Музыки | Моя волна, Колесо волн, Для вас, Мне нравится, плейлисты, исполнители, альбомы, станции, поиск | Правый клик по любому окну → «Яндекс Музыка» |
| Меню Spotify | Любимые треки, Для вас, плейлисты, исполнители, альбомы, поиск, радио по треку; нужен Premium | Правый клик по любому окну → «Spotify» |
| Джем | Общая очередь для компании: гости открывают ссылку или QR-код и добавляют треки с телефонов, ваша очередь играет после них | Меню → «Джем» → «Начать…» |
| Свои файлы | mp3, FLAC, WAV, AAC и Ogg Vorbis с диска: файлы или папка целиком, с тегами и обложками | Меню → «Открыть файлы…», «Открыть папку…» |

Там же, в меню: «Качество» — стандартное или экономия (втрое меньше трафика); «Продолжать волной» —
после плейлиста, альбома или поиска играет волна по его трекам; shuffle — без повторов или
случайный трек. Всё подробно — в [docs/features.md](docs/features.md). Чем отличается
Android-версия — в [таблице паритета](spec/parity.md).

## Быстрый старт

1. Скачайте сборку из [Releases](https://github.com/Kickoman/QiYaa/releases): `.deb` или AppImage
   для Linux, установщик или zip для Windows, `.dmg` для macOS
   ([как поставить](docs/install.md)).
2. Запустите QiYaa: откроется окно входа. Откройте ya.ru/device и введите показанный код.
3. Правый клик по любому окну → «Яндэкс Музыка» → «Мая хваля» (интерфейс по умолчанию на
   белорусском; язык меняется в меню → «Мова»). Spotify — в подменю «Spotify» (нужен Premium),
   свои файлы — «Адкрыць файлы…» или «Адкрыць папку…».

Собрать самому (Ubuntu 24.04):

```sh
sudo apt install build-essential cmake ninja-build qt6-base-dev qt6-tools-dev qt6-l10n-tools \
  libqt6opengl6-dev libgl-dev
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=RelWithDebInfo && cmake --build build
./build/QiYaa
```

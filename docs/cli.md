# Командная строка и переменные окружения

Обычно QiYaa запускают без параметров. Параметры ниже нужны для проверки звука и интерфейса, для
скриншотов и для CI. Как они устроены внутри — в [src/app/README.md](../src/app/README.md#maincpp).

## Параметры

| Параметр | Что делает |
|---|---|
| `--help`, `--version` | Показать справку или версию и выйти |
| `--offline` | Не подключаться к Яндекс Музыке при запуске (войти через меню всё равно можно) |
| `--play-file <путь>` | Играть локальный mp3, flac или wav вместо Яндекс Музыки — проверка звука. Файл подаётся кусками, как при скачивании; в плейлисте его нет. Включает `--offline` |
| `--skin <файл.wsz>` | Скин только на этот запуск, выбранный в меню скин не меняется |
| `--scale <x>` | Размер окон только на этот запуск: от 1 до 4, с шагом 0,05 (например, `1.5`) |
| `--demo` | Заполнить плейлист девятью примерами — проверка интерфейса без аккаунта (звука у них нет) |
| `--text <текст>` | Показать текст в бегущей строке (для скриншотов) |
| `--screenshot <файл.png>` | Нарисовать все окна в PNG и выйти, см. ниже |

**`--screenshot`.** Работает и без экрана, с `QT_QPA_PLATFORM=offscreen`. QiYaa запускается без
звука, без сети, без медиаклавиш и с настройками по умолчанию во временной папке, которая
удаляется при выходе, так что картинка зависит только от параметров (`--skin`, `--scale`,
`--demo`, `--text`), сборки и платформы. Вместе с `--play-file` файл играет, а снимок делается
через 1,5 с, чтобы визуализация была в движении.

```sh
QT_QPA_PLATFORM=offscreen QiYaa --screenshot shot.png --demo --scale 2
```

## Переменные окружения

| Переменная | Что делает |
|---|---|
| `QIYAA_TOKEN` | Токен Яндекс Музыки; важнее файла `token` (см. [install.md](install.md#вход-в-яндекс-музыку)) |
| `QIYAA_AUDIO_BACKEND` | Звуковая подсистема miniaudio по имени: `pulseaudio`, `alsa`, `wasapi`, `directsound`, `coreaudio`… или `null` — звука нет, но время идёт как при воспроизведении. Неизвестное имя пишет предупреждение и оставляет выбор по умолчанию |
| `QIYAA_NATIVE_WAYLAND=1` | Linux: нативный Wayland вместо XWayland (см. [install.md](install.md#wayland)) |
| `QT_QPA_PLATFORM` | Платформа Qt; если задана, QiYaa её не меняет. `offscreen` — без экрана |
| `QIYAA_TELEMETRY_URL` | Сборка с телеметрией: куда её отправлять вместо адреса из сборки, например на свой сервер джема (см. [telemetry.md](telemetry.md)) |

Переменные, которые читают только тесты (`QIYAA_UPDATE_GOLDEN`, `QIYAA_TEST_SHOTS` и другие), —
в [tests/README.md](../tests/README.md).

## Коды выхода

| Код | Когда |
|---|---|
| 0 | Обычный выход; скриншот сохранён; `--help`, `--version` |
| 1 | Скриншот не сохранился (нельзя записать файл, неизвестное расширение); неизвестный параметр или параметр без значения |
| 2 | Внутренняя ошибка — это баг: QiYaa пишет `QiYaa: internal error: <текст>` в stderr |
